# 📖 Glossário de Cibersegurança

Glossário dos principais conceitos utilizados no projeto **Mini Guia de Cibersegurança**, organizado para facilitar a consulta e o aprendizado de iniciantes.

---

## A

### ACK
Sigla para **Acknowledgment**. É uma confirmação enviada pelo protocolo TCP indicando que os dados foram recebidos corretamente.

### Ataque cibernético
Ação realizada contra sistemas, redes, dispositivos ou dados com o objetivo de explorar vulnerabilidades, interromper serviços, roubar informações ou obter acesso não autorizado.

### Autenticação
Processo utilizado para verificar a identidade de um usuário, dispositivo ou serviço.

### Autorização
Processo que determina quais recursos ou ações um usuário autenticado pode acessar ou executar.

---

## B

### Backdoor
Mecanismo que permite acesso a um sistema ignorando os métodos normais de autenticação ou segurança.

### Botnet
Rede de dispositivos infectados e controlados remotamente por um atacante.

---

## C

### Captura de pacotes
Processo de interceptar e analisar pacotes que trafegam por uma rede.

Ferramentas como o **Wireshark** podem ser utilizadas para estudar esse tráfego em ambientes autorizados.

### Cibersegurança
Conjunto de práticas, tecnologias e procedimentos utilizados para proteger sistemas, redes, dispositivos e informações contra ameaças digitais.

### CIDR
Sigla para **Classless Inter-Domain Routing**. É uma forma de representar redes IP utilizando uma notação como `192.168.1.0/24`.

### Criptografia
Técnica utilizada para proteger informações transformando dados legíveis em uma forma que somente pessoas ou sistemas autorizados possam interpretar.

---

## D

### DDoS
Sigla para **Distributed Denial of Service**. Ataque distribuído de negação de serviço que utiliza vários dispositivos para gerar grande quantidade de tráfego contra um alvo.

### DHCP
Sigla para **Dynamic Host Configuration Protocol**. Protocolo responsável por fornecer automaticamente configurações de rede, como endereço IP, gateway e servidor DNS.

### DNS
Sigla para **Domain Name System**. Sistema responsável por traduzir nomes de domínio, como `example.com`, em endereços IP.

### DNS Query
Consulta enviada a um servidor DNS para descobrir informações relacionadas a um domínio, normalmente seu endereço IP.

---

## E

### Endereço IP
Identificador utilizado para localizar um dispositivo em uma rede.

Exemplo:

`192.168.1.10`

### Endereço MAC
Identificador associado à interface de rede de um dispositivo, normalmente representado por valores hexadecimais.

Exemplo:

`00:11:22:33:44:55`

### Ethernet
Tecnologia amplamente utilizada para comunicação em redes locais (LAN).

---

## F

### Firewall
Sistema de segurança que controla o tráfego de entrada e saída de uma rede ou dispositivo com base em regras definidas.

### FTP
Sigla para **File Transfer Protocol**. Protocolo utilizado para transferência de arquivos entre sistemas.

---

## H

### Handshake TCP
Processo utilizado pelo TCP para estabelecer uma conexão.

O estabelecimento tradicional utiliza três etapas:

1. SYN
2. SYN-ACK
3. ACK

### HTTP
Sigla para **Hypertext Transfer Protocol**. Protocolo utilizado para comunicação entre clientes e servidores na Web.

### HTTPS
Versão do HTTP protegida por criptografia utilizando TLS.

### Header
Cabeçalho de um protocolo ou mensagem que contém informações de controle e metadados.

---

## I

### ICMP
Sigla para **Internet Control Message Protocol**. Protocolo utilizado para mensagens de controle e diagnóstico de redes.

O comando `ping`, por exemplo, utiliza ICMP em seu funcionamento tradicional.

### IDS
Sigla para **Intrusion Detection System**. Sistema utilizado para detectar atividades suspeitas ou possíveis intrusões.

### IPS
Sigla para **Intrusion Prevention System**. Sistema capaz de detectar e bloquear determinados tipos de atividades maliciosas.

---

## L

### LAN
Sigla para **Local Area Network**. Rede local que conecta dispositivos em uma área limitada, como uma residência, laboratório ou empresa.

### Loopback
Interface de rede utilizada para comunicação interna do próprio dispositivo.

No IPv4, o endereço mais conhecido é:

`127.0.0.1`

---

## M

### Malware
Software desenvolvido para executar ações maliciosas ou não autorizadas.

Exemplos:

- Vírus
- Worm
- Trojan
- Ransomware
- Spyware

### Man-in-the-Middle
Ataque no qual um invasor consegue interceptar ou manipular a comunicação entre duas partes.

---

## N

### NAT
Sigla para **Network Address Translation**. Técnica utilizada para traduzir endereços IP, permitindo, por exemplo, que vários dispositivos de uma rede privada compartilhem um endereço IP público.

### Nmap
Ferramenta utilizada para descoberta de hosts, identificação de serviços e análise de redes em ambientes autorizados.

### Network
Termo em inglês para **rede**. Em informática, representa um conjunto de dispositivos conectados para comunicação e compartilhamento de recursos.

---

## P

### Pacote
Unidade de dados transmitida através de uma rede.

### Phishing
Técnica de engenharia social utilizada para tentar enganar uma pessoa e obter informações como senhas, credenciais ou dados financeiros.

### Ping
Ferramenta utilizada para verificar a conectividade entre dispositivos de uma rede.

### Porta
Número lógico utilizado para identificar serviços ou processos de comunicação em um dispositivo.

Exemplos comuns:

| Porta | Protocolo/Serviço |
|---:|---|
| 22 | SSH |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |
| 21 | FTP |

### Protocolo
Conjunto de regras que define como dispositivos devem se comunicar em uma rede.

Exemplos:

- TCP
- UDP
- IP
- HTTP
- DNS
- DHCP
- ICMP

---

## R

### Ransomware
Tipo de malware que normalmente bloqueia ou criptografa dados e exige algum tipo de pagamento em troca da tentativa de recuperação do acesso.

### Rede
Conjunto de dispositivos conectados capazes de trocar informações.

### Retransmissão TCP
Reenvio de um segmento TCP quando o remetente entende que os dados podem não ter sido recebidos corretamente.

---

## S

### Segmento TCP
Unidade de dados utilizada pelo protocolo TCP.

### Servidor
Sistema que fornece serviços ou recursos para outros dispositivos, chamados de clientes.

### Sniffer
Ferramenta ou mecanismo utilizado para capturar e analisar tráfego de rede.

### SYN
Flag TCP utilizada para iniciar o processo de estabelecimento de uma conexão.

### SYN-ACK
Resposta TCP que confirma o SYN recebido e envia um SYN para continuar o estabelecimento da conexão.

### SSH
Sigla para **Secure Shell**. Protocolo utilizado para acesso remoto seguro a sistemas.

---

## T

### TCP
Sigla para **Transmission Control Protocol**. Protocolo orientado à conexão que fornece mecanismos para entrega confiável e ordenada dos dados.

### TCP/IP
Conjunto de protocolos utilizado como base para a comunicação na Internet e em muitas redes modernas.

### TLS
Sigla para **Transport Layer Security**. Protocolo criptográfico utilizado para proteger comunicações, como conexões HTTPS.

### Tráfego de rede
Conjunto de dados que circulam entre dispositivos através de uma rede.

### Trojan
Malware que se apresenta ou se disfarça como um software legítimo para induzir o usuário a executá-lo.

---

## U

### UDP
Sigla para **User Datagram Protocol**. Protocolo de transporte que não estabelece uma conexão antes do envio e não oferece a mesma garantia de entrega do TCP.

É utilizado em aplicações nas quais velocidade e baixa latência podem ser mais importantes que a retransmissão de todos os dados.

---

## V

### Vulnerabilidade
Falha ou fraqueza em um sistema, aplicação, dispositivo ou processo que pode ser explorada para comprometer sua segurança.

### VPN
Sigla para **Virtual Private Network**. Tecnologia que cria um canal de comunicação protegido entre dispositivos ou redes através de uma infraestrutura de comunicação existente.

---

## W

### WAN
Sigla para **Wide Area Network**. Rede que cobre uma área geográfica extensa, podendo conectar diferentes cidades, regiões ou países.

### Wi-Fi
Tecnologia de comunicação sem fio utilizada para conectar dispositivos a uma rede.

### Wireshark
Ferramenta de análise de protocolos de rede que permite capturar e examinar pacotes de comunicação.

É muito utilizada para estudos de redes, troubleshooting e análise de tráfego em ambientes autorizados.

---

## 🧩 Conceitos importantes para iniciantes

### Confidencialidade
Garantia de que informações somente sejam acessadas por pessoas ou sistemas autorizados.

### Integridade
Garantia de que os dados não sejam alterados de maneira indevida.

### Disponibilidade
Garantia de que sistemas e informações estejam disponíveis quando necessários.

Esses três conceitos formam a conhecida **Tríade CIA** da segurança da informação:

**Confidencialidade + Integridade + Disponibilidade**

---

## 🔎 Relação entre os principais conceitos

Um exemplo simples de comunicação na Internet:

```text
Usuário
   │
   ▼
Aplicação
   │
 HTTP / HTTPS
   │
   ▼
 TCP / UDP
   │
   ▼
 IP
   │
   ▼
Ethernet / Wi-Fi
   │
   ▼
Rede
```

Durante essa comunicação, ferramentas como o **Wireshark** podem ser utilizadas para observar os pacotes e estudar protocolos como TCP, UDP, DNS, HTTP, TLS e ICMP.

---

## ⚠️ Uso responsável

Os conhecimentos apresentados neste glossário devem ser utilizados para:

- Estudo de redes;
- Aprendizado de cibersegurança;
- Administração de sistemas;
- Diagnóstico de problemas;
- Laboratórios próprios;
- Ambientes em que exista autorização para realizar testes.

Nunca realize testes de segurança em sistemas, redes ou dispositivos de terceiros sem autorização.
